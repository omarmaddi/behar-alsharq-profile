# إعلان بحار الشرق — فيديو ثلاثي الأبعاد بتقنية الخداع البصري (Anamorphic / Naked-eye 3D)

فيديو إعلاني لعرضه على شاشات LED في شاحنات **بحار الشرق للتسويق والإعلان**، مصمم بنفس فلسفة الفيديوهات المرجعية
(Diet Cola, KFC, Qatar Airways, Anamorphic Waves, Naked-eye 3D):

- **الكاميرا ثابتة تماماً** وتعرض "صندوقاً" عميقاً مضيئاً داخل إطار أسود — على شاشة LED يختفي الأسود فيبدو الصندوق كأنه محفور داخل جسم الشاحنة.
- **العناصر تخرج من الصندوق وتتجاوز حدود الإطار** باتجاه المشاهد (الموج، الشمس، زر التشغيل، الحروف العربية المجسمة، "3D")، مع ظلال حقيقية على أرضية الصندوق — وهذا ما يصنع الخداع البصري.

## الفكرة: "شروق بحار الشرق" (32 ثانية — Loop متصل)

استوديو داكن (كحلي/جرافيت) بإطار أسود رفيع على نسبة 2:1 (شاشة 4 م × 2 م)، حتى تتوهج ألوان الهوية:
الشمس الذهبية، الأمواج الزرقاء، وشاحنات الشركة الزرقاء — وكل شيء يخرج من الصندوق نحو المارة.

| الوقت | المشهد |
|---|---|
| 0 – 1.9 ث | خط ذهبي يرسم الصندوق من العمق نحو المشاهد، ثم تضيء الإضاءة |
| 1.4 – 7.8 ث | **البحر** يملأ الصندوق وموجة ضخمة تندفع **خارج الشاشة** مع رذاذ على المارة |
| 5.2 – 11.9 ث | **الشمس الذهبية تشرق من البحر**، تطير خارج الإطار وتتحول إلى **شعار الشركة** (الأمواج تلتف، وزر التشغيل يقفز نحو المشاهد) + "بحار الشرق — للتسويق والإعلان" |
| 11.8 – 21.8 ث | **عدن تنبثق كمجسم ورقي (Pop-up)** وقت الغروب: الجبال، قلعة صيرة، برج الساعة، المنارة، النخيل، البحر، وسماء بألوان الهوية — **طيور النورس تطير خارج الشاشة** وطريق يمتد نحو المشاهد |
| 14.6 – 18.1 ث | **شاحنة بحار الشرق** (كابينة زرقاء، صندوق LED بإطار أسود، شريط أصفر بأرقام التواصل) تخرج من المدينة وتقود **خارج الشاشة** نحو المارة |
| 15.7 – 21.8 ث | شاحنة ثانية تقف بجانبها وشاشتها تعرض "إعلانك هنا"، ثم **تنفجر المنتجات من شاشتها** (علب، عصير، هاتف) نحو المشاهد |
| 21.8 – 26 ث | **"3D"** عملاقة تخرج وتدور + "نصمم إعلانك — بتقنية الخداع البصري — وشاشاتنا تُخرجه إليك" |
| 26 – 32 ث | الخاتمة: الشعار + "إعلانك ... يصل للجميع" + 784006800 \| 784007800 + ‎@baharalsharq ثم تطفأ الإضاءة (Loop) |

## الملفات

- `bahar-alsharq-3d-truck-ad.mp4` — الفيديو النهائي 1920×960 (نسبة 2:1 = شاشة 4 م × 2 م)، 30 إطار/ث، 32 ثانية.
- `src/scene.js` — المشهد والتسلسل الزمني (three.js)، كل إطار دالة في الزمن.
- `src/truck.js` — نموذج شاحنة الشركة بشاشات LED متحركة.
- `src/aden.js` — مجسم عدن (الجبال، قلعة صيرة، برج الساعة، المنارة، النخيل) + النورس + الطريق.
- `src/brand.js` — الشعار ثلاثي الأبعاد، الحروف العربية المجسمة، ومحتوى شاشات الشاحنات.
- `src/products.js` — منتجات العرض التي تخرج من شاشة الشاحنة.
- `src/shape-text.js` — تشكيل النص العربي بـ HarfBuzz وتحويله لمسارات تُجسَّم بعمق حقيقي (خط Cairo).
- `render.js` — تصيير الإطارات في Chromium بدون واجهة.

## إعادة التصيير / تغيير المقاس

مقاس الشاشة غير ثابت: يمكن إخراج نسخة بأي دقة تطابق شاشة الشاحنة بالضبط (مهم جداً للخداع البصري):

```bash
npm install
node src/shape-text.js                       # عند تعديل النصوص
node render.js --w 1920 --h 960 --fps 30 --out frames
ffmpeg -framerate 30 -i frames/%05d.png -c:v libx264 -pix_fmt yuv420p -crf 16 out.mp4
```

معاينة حية: شغّل أي خادم ملفات في هذا المجلد وافتح `index.html?preview`.
