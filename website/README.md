# موقع بحار الشرق للتسويق والإعلان

موقع ثابت (HTML/CSS/JS) — بدون قاعدة بيانات أو لوحة تحكم، لذلك سريع جداً وآمن ولا يحتاج تحديثات أمنية.

## الرفع على الاستضافة
ارفع **محتويات مجلد `website/` كما هي** (باستثناء مجلد `src/` اختياري) إلى جذر الموقع:

- **استضافة cPanel / Apache:** ارفع الملفات إلى `public_html`. ملف `.htaccess` يفعّل تلقائياً: HTTPS، التحويل إلى www، رؤوس الأمان، الضغط، والتخزين المؤقت.
- **Netlify أو Cloudflare Pages (مجاني وأسرع):** اسحب المجلد في لوحة التحكم. ملف `_headers` يفعّل رؤوس الأمان والتخزين المؤقت.

## الأمان
- سياسة أمان محتوى صارمة (CSP): لا سكربتات أو خطوط أو ملفات من أي طرف ثالث.
- HSTS، منع التضمين داخل إطارات (Clickjacking)، nosniff، Permissions-Policy.
- نموذج التواصل لا يرسل بيانات لأي خادم؛ يفتح واتساب برسالة جاهزة فقط.

## محركات البحث (SEO)
- عنوان ووصف عربي، بيانات منظمة `AdvertisingAgency` (JSON-LD)، Open Graph للمشاركة،
  `sitemap.xml` (مع الصور والفيديو)، `robots.txt`، روابط canonical.
- بعد الرفع: أضف الموقع إلى **Google Search Console** وأرسل `https://www.bahrshrq.com/sitemap.xml`،
  وأنشئ/حدّث **Google Business Profile** للشركة في عدن.

## الأداء
- صور WebP بمقاسين (srcset) مع أبعاد ثابتة لمنع اهتزاز الصفحة، تحميل كسول، خطوط woff2 محلية مع preload،
  فيديوهات مضغوطة تتوقف تلقائياً خارج الشاشة، واحترام إعداد «تقليل الحركة».

## التعديل
- المحتوى في `src/index.src.html` و `src/build.py`، ثم: `python3 src/build.py` لتوليد `index.html`.
- رقم واتساب في `assets/js/main.js` (`WA`) وفي روابط `wa.me` داخل الصفحة.
